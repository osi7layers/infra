# 단계별 구성 기록

QA A-IAC-01의 "CLI 단계 기록 문서". 단계를 진행할 때마다 채운다. 진행 방법은 `README.md`.

## 1. 콘솔 단계

| 항목 | 값 |
|---|---|
| 날짜 / 진행자 | 2026-10-14 / 명호 |
| 만든 범위 | VPC, 서브넷 4, IGW, NAT, 라우트 테이블 3, SG 2(+기본 SG 비우기), ECR 1 |
| 캡처 위치 | 명호님 PC `Desktop\AWS 캡처20261014` (리소스 맵, 라우트 테이블, SG 2개 인바운드·아웃바운드, ECR 설정·수명 주기) |
| 삭제 완료 확인 | 기본 VPC 외 VPC·서브넷·라우트 테이블·SG·IGW·ENI 0, 살아 있는 NAT 0, EIP 0, ECR 0 |
| 배운 점 / 헷갈린 점 | 아래 |

세 번째 시도에서 Terraform과 같은 구성이 됐다. 앞의 두 번은 아래 실수를 고치다 지웠다.

| 실수 | 결과 | 배운 점 |
|---|---|---|
| 태그 키 한 칸에 `Project=osi7, ManagedBy=console`을 통째로 입력 | 태그로 리소스를 찾을 수 없음 | 태그는 한 줄에 키 하나, 값 하나 |
| `-c` 서브넷을 2a에 만듦 | AZ 이중화가 안 됨, 서브넷을 다시 만듦 | 서브넷 AZ는 만든 뒤 바꿀 수 없다 |
| 라우트 테이블 이름에 `: 0.0.0.0/0`을 적고 경로는 추가 안 함 | 인터넷·NAT로 나가는 경로 없음 | 경로는 라우팅 탭 → 라우팅 편집에서 넣는다 |
| VPC의 DNS 호스트 이름을 켜지 않음 | (EKS였다면) 노드가 클러스터에 등록되지 않음 | 콘솔 기본값은 꺼짐, Terraform은 켬 |
| 서브넷 이름 `osi-app-a` (7 빠짐) | 이름이 Terraform과 다름 | 이름은 비교 기준이므로 그대로 맞춘다 |
| ECR 태그 키 `Managedby` | `ManagedBy` 태그 검색에 안 잡힘 | 태그 키는 대소문자를 구분한다 |
| SG 규칙 설명을 비워 둠 | CLI·Terraform과 비교하면 설명만 다름 | 동작에는 영향 없음 |

- SG 두 개는 서로를 참조하므로 규칙 없이 먼저 만들고 나중에 규칙을 붙여야 한다. 지울 때도 참조 규칙을 먼저 지운다.
- 삭제한 NAT는 1시간쯤 콘솔에 `Deleted`로 남고, 태그 검색(`resourcegroupstaggingapi`)에는 더 오래 남는다. NAT는 상태로 확인한다.

## 4. Terraform 단계와 비교

| 항목 | 값 |
|---|---|
| 날짜 | 2026-10-22 |
| `terraform plan -detailed-exitcode` 종료 코드 | 0 (No changes) |
| `diff snapshot-cli.txt snapshot-terraform.txt` | 차이 4종, 모두 예상된 차이 (아래 표) |

### 차이 목록

| 항목 | CLI | Terraform | 예상된 차이인가 |
|---|---|---|---|
| ECR 리포지토리 수 | 1 | 5 | 예 (CLI는 1개만 만듦) |
| ECR 리포지토리 이름 | osi-shop/frontend | ecommerce/web | 예 (2026-10-15 이름 변경. CLI를 다시 돌리면 같아짐) |
| ECR 수명 주기 설명 문구 | 영어 | 한글 | 예 (보관 개수 10은 같아야 함) |
| EKS 클러스터 SG | 없음 | 있음 (`eks-cluster-sg-osi7-eks-*`, 규칙 3개) | 예 (EKS가 만듦) |
| ALB SG → 노드 SG 포트 | 30000-32767 (NodePort) | 9080(APISIX), 7085(상태 검사) | 예 (CLI 단계 뒤 2026-10-19·21에 진입을 ALB → APISIX Pod 직접(target-type ip)으로 바꿈. `02-security.sh`는 이미 9080·7085로 고쳐 두어 다시 돌리면 같아짐) |

- 수명 주기 설명 문구는 이번 비교에서 차이로 나오지 않았다. VPC, 서브넷, 라우트, NAT, IGW, 노드 역할의 정책 이름은 같다.
- 결론: CLI로 만든 구성과 Terraform 구성은 이후 설계 변경(진입 포트)과 EKS가 만드는 리소스를 빼면 같다 (QA A-IAC-01).
